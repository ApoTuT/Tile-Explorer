# Tile Explorer 复现原型设计 · 0.3

更新日期：2026-10-19。本轮根据用户反馈，将范围收敛为 **9 关、3 个旅行主题、3 个功能键**，先确认基础手感。

## 玩法依据与本版目标

保留原作的短循环：观察层叠牌阵 → 点击可取牌 → 管理有限暂存槽 → 三张消除 → 揭开下一层 → 清空棋盘。官方商店描述支持点按、三张消除与逐关推进；本版的七格容量、具体遮挡算法和道具行为为原型约定。[Google Play 官方页](https://play.google.com/store/apps/details?hl=en_US&id=com.oakever.tiletrip)、[App Store 官方页](https://apps.apple.com/gb/app/tile-explorer-triple-match/id6498883328)

交付保留 Python 标准库规则引擎、本地 HTTP 服务和浏览器画面。浏览器发送操作意图，Python 决定规则结果。卡通地标、简洁图标和基础反馈服务于试玩，不追求完整商业美术与动画。

## 确定规则

| 项目 | 0.3 行为 |
|---|---|
| 层叠关系 | 有更高层的存活牌与本牌矩形相交时，本牌被遮挡；边缘相接不计遮挡 |
| 普通取牌 | 只允许取未被遮挡的牌 |
| 底牌可见 | 被压住的牌自然露出原大图案，不重复绘制角标、不变灰隐藏；可观察不代表可普通取走 |
| 暂存槽 | 七格，同图案自动相邻；第三张进入后立刻消除 |
| 胜负 | 先消除，再检查七格是否全满；棋盘与暂存槽均清空即通关 |
| 时间 | 无倒计时 |
| 选关 | 九关均可自由选择，切换会重开对应牌局 |
| 撤回 | 将暂存槽最近放入且尚未消除的一张牌送回棋盘，不复原已消除的整组三张 |
| 魔法笔 | 激活后点击一张被遮挡的牌，直接送入暂存槽；占槽与消除规则不变 |
| 重新排布 | 暂存槽牌退回，全部剩余牌重新排布；保留剩余图案总数，满槽失败后也可救援 |
| 工具限制 | 三个工具均无能量要求和次数上限 |

本版只有一套玩法，没有经典/回声模式切换、提示按钮或回声能量。重开与选关属于导航操作。未来点子保留于 [IDEAS.md](IDEAS.md)，其中的实验不表示已经实现。

全局图案库为水果六种、汽车与交通六种、宠物六种，各关按参数选择其中一部分。牌数、图案数、层数和预设取牌路径压力是难度设计参数；它们渐增并不能代替真人试玩的难度评估。

生成器先建立层叠位置和合法移除顺序，再填入总数为三的倍数、暂存槽占位受控的图案序列，保存通关路线供内部回放校验。重排也为新的剩余局面建立路线。保证初始局和重排局存在解，玩家偏离后可能进入死局；前端无需展示求解与证书术语。

0.3 按用户截图将牌阵改为紧密整体：底层五列连成轮廓，并保留中央空隙；上层按半格网格跨住两张或更多下层牌。同层不互相重叠。以半单位网格计算实际剩余面积，保证每张牌至少露出四分之一，并有一块完整的一单位方形可点击区域。48张关卡按32/9/5/2四层分配。少量剩余牌重排时会减少层数，避免为了深度挤成不可辨认的小堆。

牌面改为有深色描边、高光和圆润体积的卡通图集，白银色厚方牌提供层级感；底牌亮度不额外降低。图集在CSS中按透明边界校准居中并放大，图案不依赖外部网络。上方暂存槽采用银边深色凹槽，方便同时观察槽位与牌阵。

## 存档、验证与后续

进行中的牌局按浏览器会话隔离，保存在 Python 服务内存；同一会话刷新可继续，停止服务会结束该局。已完成记录保存到项目 `.local/travel-progress-v2.json`，旧版成绩不混入本版；没有账号或云同步，也未使用浏览器 localStorage 保存牌局。

验证重点是三消与满槽顺序、遮挡判定、只撤回一张未消除牌、魔法笔直接取底牌、重排后的图案守恒与可解性，以及九关参数。实际测试结果记录在迭代日志，设计计划不代替测试结果。

当前仍依赖本地 Python 服务。用户提供的比赛海报提到 H5 和至少50关；本轮按用户当前要求只交付九关复现原型，待确认玩法后再讨论比赛适配。原型游玩中无在线 AI 调用，后续脑暴也应先验证一个点子是否带来有趣选择，再决定是否整合。
