## v0.2：候选槽小剧场（规划中）

方案整理日期：2026-10-20。基于正式 v0.1 继续更新。以下均为计划内容，当前游戏尚不具备这些声音与互动。

### 本代希望带来的体验

把候选槽变成七个小角色共处的小舞台。每张牌进入槽里都会打个招呼，表现出自己的性格；碰到熟悉的邻居时，还会自然接上一段小戏。

玩家正常取牌就能遇到这些彩蛋。组合只带来声音、表情和小动作，既不改变消除结果，也不增加需要额外计算的玩法规则。

### 新增一：18 种牌都有自己的声音和性格

沿用当前水果、交通、宠物三组牌面，为全部 18 种牌设计专属反馈。以下是首批制作方向，最终声音以实际试听为准。

| 牌面 | 性格 | 进入候选槽时的表现 |
|---|---|---|
| 苹果 | 元气 | 清脆“啵”，轻轻弹一下 |
| 香蕉 | 调皮 | 一小段滑音，左右摇摆 |
| 樱桃 | 默契双胞胎 | 两声短音，交替摆动 |
| 葡萄 | 胆小 | 细碎“噗噗”，紧张抖动 |
| 橙子 | 豪爽 | 圆润“咚”，落下后回弹 |
| 草莓 | 害羞 | 轻柔铃音，倾斜并冒爱心 |
| 汽车 | 急性子 | 短促喇叭，向前探一下 |
| 出租车 | 热情 | 两声招呼喇叭，闪一下光 |
| 巴士 | 稳重 | 车门提示音，缓慢点头 |
| 火车 | 爱出风头 | 一声短汽笛，轻轻昂起 |
| 自行车 | 轻快 | 清脆车铃，左右轻晃 |
| 小摩托 | 淘气 | 短促引擎音，轻微震动 |
| 猫 | 好奇、傲娇 | 短“喵”，歪头观察 |
| 狗 | 热情 | 短“汪”，兴奋弹跳 |
| 兔子 | 谨慎 | 轻轻“啾”，缩起后再探头 |
| 熊猫 | 慢半拍 | 含糊鼻音，慢慢晃一下 |
| 狐狸 | 机灵 | 轻快上扬音，探身并冒闪光 |
| 小熊 | 憨厚 | 低沉“唔”，身体轻轻一颠 |

角色在槽中等待时以安静为主，偶尔做一个无声小动作。惊叹号、汗滴、爱心、音符等小表情帮助玩家看懂情绪；关闭声音后仍能看到这些反应。

### 新增二：不同牌面在槽中会互相接戏

首批计划制作 6 组双牌互动、2 组三种不同牌面的互动。只要相关牌面同时留在槽中，新加入的角色就有机会发起表演，不要求玩家刻意安排相邻位置。

| 组合 | 玩家看到和听到的小剧场 | 可出现的现有关卡 |
|---|---|---|
| 苹果 + 猫 | 猫凑近观察，苹果紧张晃一下 | 1–3 |
| 汽车 + 猫 | 汽车鸣笛，猫缩一下并冒惊叹号 | 1–3 |
| 香蕉 + 出租车 | 香蕉弹起打招呼，出租车双鸣回应 | 3–6 |
| 狗 + 巴士 | 狗兴奋连跳，巴士闪光回应 | 4–6 |
| 葡萄 + 兔子 | 兔子探头，葡萄抖动并冒汗 | 5–9 |
| 火车 + 熊猫 | 火车吹汽笛，熊猫慢半拍惊醒 | 7–9 |
| 苹果 + 汽车 + 猫 | 汽车发出出发信号，苹果和猫依次回应，形成三拍节奏 | 1–3 |
| 葡萄 + 火车 + 熊猫 | 汽笛响起，葡萄紧张摇晃，熊猫困倦地点头 | 7–9 |

这些范围表示相关牌种可以在关卡中共现，具体仍需玩家取到相应牌并留在槽里。这里的“三牌互动”是三种不同牌的小剧场，与三张同类自动消除分开处理。

一次只演一段，避免所有角色同时吵闹。同一段戏不会连续反复出现；新操作可以自然结束旧表演。

### 新增三：三消有自己的退场收尾

凑齐三张同类后，角色会用对应的声音和短动作一起离场。第三张入槽与三张消除衔接起来，让玩家能感受到“终于凑齐”的瞬间。

三消反馈会优先于普通组合互动。所有动作保持短促，玩家可以继续点牌，无须等待角色演完。

### 新增四：可控制的声音与动态反馈

- 增加音效开关，方便在安静环境下游玩。
- 适配减少动态效果的偏好，保留必要的视觉反馈。
- 角色进出槽、撤回、重排和切关时，表演随当前局面结束或更新。
- 刷新页面或切回游戏时，不补播已经发生过的声音和小剧场。
- 声音或装饰暂时不可用时，仍可正常消牌。

### 本代完成时应达到的体验

全部 18 种牌都有能辨认的反馈，8 组互动能自然触发；快速点牌不让人等待，也不会造成声音堆积。角色自动靠拢或被撤回后，反应仍属于正确的那张牌。桌面与手机上，图案、槽位和可点击区域都保持清楚。

当前状态：**待实施、待试玩、待验证，尚未发布正式 v0.2。** 具体实现、节奏参数、素材要求和验证计划见 [v0.2 技术方案](technical/v0.2.md)。

## v0.1：九关旅行原型（已实现）

首次提交日期：2026-10-20。正式版本标签：`v0.1`。这是首次纳入 Git 的完整可玩基线，汇总了下方两个开发阶段的成果，并不表示所有功能都在首次提交当天开发。

### 新增一：三城九关的完整旅行

从巴黎出发，经过京都，再到纽约。每三关共享一座城市的卡通地标背景，每关有自己的标题和一则知识明信片，附可点击的官方来源。

| 城市 | 关卡 | 各关牌数 | 各关图案种类 | 各关层数 |
|---|---|---|---|---|
| 巴黎 | 1 / 2 / 3 | 12 / 18 / 24 | 3 / 4 / 5 | 1 / 2 / 2 |
| 京都 | 4 / 5 / 6 | 27 / 30 / 33 | 6 / 7 / 8 | 3 / 3 / 3 |
| 纽约 | 7 / 8 / 9 | 36 / 42 / 48 | 9 / 10 / 12 | 3 / 4 / 4 |

九关均可自由选择。随着旅行推进，牌数、图案种类和遮挡深度逐步增加；实际难度曲线仍需后续试玩调整。完成关卡可留下旅行进度和星级记录。

### 新增二：完整的层叠三消体验

- 点击没有被上层压住的牌，收入七格候选槽。
- 相同图案自动靠拢，凑齐三张立即消除。
- 第七张恰好凑成三张时，先完成消除，仍能继续游玩；消除后七格仍全满才失败。
- 棋盘和候选槽同时清空即通关，全程没有倒计时。
- 被压住的牌仍可观察图案，方便寻找下一组目标。

初始局面和整体重排后的局面都安排至少一条通关路线；玩家任意选择之后，仍可能进入难以继续的局面。

### 新增三：三个随时可用的工具

| 工具 | 玩家获得的帮助 |
|---|---|
| 撤回 | 退回槽中最近加入且尚未消除的一张牌；已经消除的三张不会重新出现 |
| 魔法笔 | 点亮后，直接选取一张被压住的牌；入槽后照常参与三消 |
| 整体重排 | 将棋盘和候选槽中的剩余牌一起重新布置；满槽失败后也可使用 |

三个工具均无次数或能量限制。重开当前关放在选关入口中，通关后可以继续下一关。

### 新增四：18 种卡通牌面与更清楚的牌阵

水果、交通、宠物各六种，共 18 种图案。牌面采用明亮颜色、深色描边、高光和圆润体积，搭配白银色厚牌与投影。

牌阵是紧密的整体：底板连贯，上层跨牌压叠，中央留出空间。底牌直接露出原图案，亮度保持一致，便于观察。深色七格候选槽位于棋盘上方，玩家能同时留意待取牌和槽内已有图案。

棋盘适配桌面和手机，取牌后剩余牌的位置保持稳定。

### 新增五：本机离线游玩与进度记录

游戏可在本机启动后离线游玩，无需账号。相同浏览器会话刷新后可以继续当前牌局；停止本地服务后，进行中的牌局结束，已完成的旅行记录会保留。

新版成绩与早期成绩分开记录。当前原型仍需要本地服务，独立 H5 打包及比赛要求的更多关卡尚未交付。

### 当前边界与资料

v0.1 尚无候选槽角色配音和组合小剧场。旧回声模式、能量和提示功能不属于当前玩法。已实现能力及历史验证记录见 [v0.1 技术文档](technical/v0.1.md)，操作入口见 [README](../README.md)。

## 开发阶段 0.3：堆叠与图案重做（已纳入 v0.1）

日期：2026-10-19。本轮围绕用户截图，集中改善牌阵形态、图案辨认和手机观察体验。

### 从分散牌堆改为完整牌阵

上一轮分离的小牌堆改成紧密连贯的底板，上层跨住多张下层牌，整体保留中央空隙。第九关形成四层堆叠，外观更接近参考游戏的整体牌面。

### 底牌直接露出原图案

移除底牌上的小图案角标和层数圆点。下层牌与上层牌使用相同亮度，通过真实压叠自然露出一部分大图案，让玩家直接认出下面有什么。

### 18 种图案升级为卡通插画

用更饱满、明亮、有描边和体积感的图案替换早期简化图标；增加白银色厚牌和投影，使层级更清楚。

### 候选槽与移动布局调整

七格槽移至棋盘上方，改为银边深色凹槽。棋盘高度随布局适配，取牌后位置保持稳定。手机上重点检查底牌露出的部分能否准确点击，以及页面是否出现横向溢出。

历史预览：[桌面](screenshots/dense-v3.jpg)、[手机](screenshots/dense-mobile-v3.jpg)。实现与原有验证记录见 [开发阶段 0.3 技术文档](technical/dev-0.3.md)；本次未重新验证。

## 开发阶段 0.2：三城九关与工具语义（已纳入 v0.1）

日期：2026-10-19。本轮将原型收敛为九关旅行体验，先确认基础消牌循环和工具使用手感。

### 建立三城九关的内容结构

增加巴黎、京都、纽约三个旅行主题，每城三关，包含卡通背景、独立关卡标题和一条知识内容。牌数从 12 张增加至 48 张，图案从 3 种增加至 12 种，堆叠从一层增加至四层。

### 重新明确三个工具的作用

撤回调整为只退回最近加入的未消除单牌，不再回退整局历史，也不恢复已经消除的三张或倒退已获分数。魔法笔用于直接取被压住的牌，整体重排用于重新安排棋盘和槽内的全部剩余牌，三个工具均可不限次数使用。

### 增加可观察的底牌与丰富图案

当时采用分离的错位牌堆，让下层图案从牌角露出；同时引入水果、交通、宠物三组共 18 种简化图案。该表现后来在开发阶段 0.3 被紧密牌阵和卡通图案替代。

### 简化界面并分开新版成绩

移除提示、回声模式、能量和额外重开工具。底栏只保留三个功能按钮，选关时可重开当前关。新版旅行成绩与旧版记录分开，避免把不同关卡的成绩混在一起。

历史预览：[巴黎](screenshots/travel-v2.jpg)、[京都](screenshots/kyoto-v2.jpg)、[纽约](screenshots/newyork-v2.jpg)、[手机](screenshots/mobile-newyork-v2.jpg)。实现与原有验证记录见 [开发阶段 0.2 技术文档](technical/dev-0.2.md)；本次未重新验证。
