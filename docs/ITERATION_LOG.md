## 0.3：按截图重做堆叠与图案

日期：2026-10-19。

- 移除分离的错位小牌堆，改成紧密底板、跨牌压叠、中央留白；48张关卡分成32/9/5/2四层。
- 移除底牌的小角标与层数圆点；底牌以同样亮度显示原大图案，自然被上牌覆盖。
- 引入18种透明卡通图案，增加饱和度、描边、高光和体积感，配白银色厚牌与投影。素材生成和完整提示词见ASSETS_V3.md。
- 七格暂存槽移至棋盘上方，采用银边深色凹槽；棋盘高度根据实际布局自适应，选牌后位置保持稳定。
- 每张底牌保证至少25%露出面积和1单位方形点击区，每张桥牌跨至少两张下层牌；所有重排剩余张数均检查守恒与通关路线。

实际验证：45项自动测试全部通过；实测取牌、撤回、魔法笔点取自然露出的底牌、含托盘牌的整体重排。手机375px内容宽度下，第九关48张牌的36张被压牌都能命中所属牌，页面没有横向溢出；图集加载成功，无重复角标，浏览器未报告错误或警告。新预览见screenshots/dense-v3.jpg及dense-mobile-v3.jpg。

## 0.2：三城九关与工具语义（历史记录）

日期：2026-10-19。本轮按用户反馈收敛为九关复现，先验证基础玩法，不增加额外实验模式。

| 修改 | 结果与检查 |
|---|---|
| 三城九关 | 巴黎1–3、京都4–6、纽约7–9；对应卡通地标背景，每关一条短知识或人物故事，附官方来源 |
| 关卡递进 | 12/18/24/27/30/33/36/42/48张牌；图案3→12种，层数1→4层。四套种子共36条完整路线回放通过 |
| 三个工具 | 撤回槽中最近加入的未消除单牌；魔法笔直接点取被压住的牌；整体重排棋盘和槽中剩余牌。均无能量或次数限制 |
| 撤回语义 | 不再恢复整局历史，不复活已消除的三张，也不倒退已获组合分数 |
| 可见底牌 | 改为分离的错位牌堆，每层右下偏移0.65单位；底牌露角显示对应小图案。上层仍保持真实遮挡关系 |
| 丰富图案 | 18种独立本地SVG：水果、交通、宠物各6种，各关逐步引入 |
| 清理旧界面 | 移除提示、回声模式、能量与额外重开工具；选关内可重开当前关，底栏只有三个工具 |
| 存档 | 新版使用 `.local/travel-progress-v2.json`，避免把旧版成绩混入新关卡 |

实际执行 `python -m unittest discover -s tests -v`，**41项全部通过**。测试覆盖：九关递进与通关路线、三关一主题和知识来源、遮挡边界、下层露角、三消先于满槽判负、只撤回一张、魔法与重排守恒、重排可解、新存档及第九关结束边界。

浏览器实测：

- 完成巴黎第一关；先取一张再撤回，确认只退回该单牌。
- 巴黎第二关直接点击底牌露角，魔法笔成功入槽且自动关闭；撤回能恢复原位置。
- 槽内已有牌时整体重排，确认暂存槽清空，全部18张剩余牌回到新棋盘，底栏始终只有3个功能按钮。
- 切换京都第四关、纽约第九关，背景、城市标题、章节序号和知识同步更新。
- 桌面1280px与手机390px宽度检查。纽约第九关48张牌、4层时，36张被压住的牌的图案露角均能命中所属牌，未出现横向溢出。
- 检查时浏览器未报告错误或警告。JavaScript语法检查与Python编译检查通过。

真实预览位于 `screenshots/travel-v2.jpg`，另有京都、纽约与手机预览。当前逐关递进依据牌量、种类和层数构建；人的实际难度曲线仍需后续试玩调整。
