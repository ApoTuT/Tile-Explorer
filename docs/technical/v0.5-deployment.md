## 回退与存档

Nginx 配置为 `/root/my-project/Group-Buy-16009-sheng/docs/dev-ops/nginx/config/default.conf`。需要回退时，备份当时配置，仅把精确游戏入口的 return 路径改回 `/tile-explorer/releases/20261023-v05-glide-ec043a51/`，执行：

```text
docker exec group-buy-market-ui nginx -t
docker exec group-buy-market-ui nginx -s reload
```

通过后检查入口和原站首页。如其他业务改过配置，不直接整份覆盖旧备份。本次脚本对配置检查、reload、入口和原站检查设置失败回退。

`slide-v05-2` 不回放旧单格日志，当前关安全重开，设置保留。回退到旧规则也会按规则／定义身份校验，不删除所有玩家数据。旧不可变标签页继续运行原版本，进入稳定入口才能打开当前更新。
