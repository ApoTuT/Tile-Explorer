# v0.7 实现与验证记录

日期：2026-10-24。分支：`codex/v0.7-thirty-levels`。状态：已实现、本地与线上验收通过，已部署公网。[正式试玩](http://106.12.167.253/tile-explorer/)。开发基线为 `codex/v0.6-multistage` 的 `823b30d`。

## 可玩的内容

入口 `web/slide-v07.html`，首页新增 v0.7 链接；通过现有启动器运行后打开 `/slide-v07.html`。包含 30 关、6 个章节、90 星、通关顺序解锁。前三项新机制依约在 15、20、25 关第一次出现，30 关组合使用三种机制。

- 爆破卡：普通材料带一次能力，任一合成参与者带标记则在合成落点爆破，清除四邻木箱，普通材料保留。最终目标交付也能触发，中间产物不继承能力。
- 一次性花台：材料完整对齐同尺寸空花台时提前停止，消耗该处的一次机会。
- 传送门：每关一对、双向、共用一次机会；尺寸匹配且出口完整空闲才能触发，传送后结束本步。出口被占时作为普通地面经过。

第 16 关为五苹果加两橘子、收集三个桃子。16、18、23、24、28、30 各有两个已经独立验证的爆破标记变体，其他关卡固定，共 36 个变体。每个存档首次进入时确定标记位置，撤销、重试、刷新和重新进入不重新抽取。

## 与初始设计的差异

实际坐标以 `web/slide-v07/levels.js` 为准，[逐关规格](v0.7-levels.md)已同步实际材料、目标、尺寸与参考路线步数。

1. 部分新棋盘缩小为 4×3，17、29 关缩小为 4×4，减少手机点选负担和无效周转，也使完整空间验证可在开发/CI 内执行。
2. 第 19 关改为苹果×2、桃子×1、嫩芽×2、小树×1；收集目标仍为西瓜和大树。木箱减为一个，移除可挪障碍。
3. 第 24 关保留两种花台，木箱减为一个，移除可挪障碍。
4. 第 30 关用苹果×2、桃子×1替代苹果×4，保留竖向植物、横向汽车及三项机制。
5. 所有参考路线为 1–13 步，保留 20 步预算。初始“终关参考解 14–17 步”没有作为硬约束；解法长度不能代替真人难度评估。
6. 地形采用 CSS 和文字/符号绘制，合成素材继续使用现有本地 SVG，无需新增位图或网络资源。普通材料覆盖地形时显示传送/花台角标，避免隐藏重要信息。
7. `variants[].bombTileIds` 定义标记牌，解析后生成 `tiles[].effect = 'bomb'`。两个门端点可以相邻；一次穿行结束并消耗次数，因此不会出现同一步循环。

## 规则与状态实现

`web/slide-v07/engine.js` 是规则的唯一来源，版本 `slide-v07-1`、评分 `score-v07-1`。预览、提交、提示、回放和离线完整图证明均调用它。沿用四向矩形扫掠与整边合成，额外处理有限地形，不改变三条链的质量守恒。

每次动作先确定完整结果，再统一更新材料、交付、地形、能力、分数和两种操作预算。最后一步获胜优先于失败；无效动作不扣步。爆破、花台和传送不会自动引发下一次滑动或多次合成。

`session.js` 用动作日志回放恢复完整状态；撤销取整次动作的 before 快照。命名空间 `tile-explorer.slide.v07.*`，预览隔离；仅从 v0.6 迁移布尔音效/减少动态偏好。变体分配单独保存，定义哈希覆盖材料、能力、变体、尺寸、目标、地形、预算和评分。旧哈希安全重开，存储失败退化为内存并提示。

提示在 `solver-worker.js` 中执行有界搜索，超时报告未知，输入可继续；切关、撤销、重开与关闭提示使旧结果失效。参考路线仅在当前空间状态一致且剩余预算足够时采用，不从中途随意套用。

## 构建、检查与复测

```text
python main.py --no-browser
python tools/checks.py
node --max-old-space-size=6000 tools/validate_v07_levels.cjs --write
python tools/export_v07.py --output .local/h5-v07
python -m http.server 8788 --bind 127.0.0.1 --directory .local/h5-v07
node tools/playtest_v07.cjs
```

独立 H5 共 23 个文件，无账号、CDN 或规则后端依赖。`config/slide-v07.json` 同时驱动本机白名单与导出；Worker 作为本地 JS 资源登记，导出后从相对路径加载规则与内容模块。资源 manifest 允许 `.js` 作为非 HTML 自动执行资源，不绕过规范路径检查。

浏览器脚本需要可用的 Playwright 与 Edge；可用 `PLAYWRIGHT_MODULE` 指定包路径，`V07_URL` 指定主入口或静态入口，`V07_QA_OUTPUT` 指定报告目录。`?debug=1` 只用于测试选关；正常入口从第一关逐关解锁。所有实际游戏动作均通过原生输入，调试接口仅提供只读状态。
