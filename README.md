# 叠叠环游记 / Tile Explorer 原型 · v0.3 开发版

v0.3 新增独立的三关玩法 **「小狗长大啦」**：把上层小狗拖到可用的下层小狗上，两张对齐后长成金毛并自动交付。本轮根据第三关残局反馈，增加一个只能放一张牌的**临时窝**：先把小狗拖进去借个位，解除遮挡，再把窝内小狗拖回下层完成配对。下层牌间距收紧为 6 世界单位。可免费完整撤销、重开和选关，进度保存在浏览器。原九关旅行模式仍可从首页游玩，正式发布标签仍为 v0.1。

三关递进为直接配对、必须借位、组合两种动作。借位和合成都记一次操作，没有操作次数上限。临时窝不能放第二张，窝内牌只能通过合成取回；其他空地松手仍会回位。本轮规则为 merge-v03-2，三关每个合法可达状态都已验解，均可继续通关。规则和证据见 [当前实现记录](docs/technical/v0.3.md)。

2026-10-21 继续整理交互与代码：拖动按浏览器帧合并更新，小屏吸附范围随缩放调整，无效落点用可打断的短动画回位；新操作不必等待整段成长动画。牌、目标槽和临时窝按 ID 复用节点，规则状态与历史交由独立会话模块管理。玩法与三关布局不变。统一自动检查与主模式、静态 H5 浏览器复测已通过，实现已推送至 [PR #2](https://github.com/ApoTuT/Tile-Explorer/pull/2)，尚未合并或正式发布。

启动后访问 [小狗长大啦](http://127.0.0.1:8765/merge-v03.html)，或点击首页顶部的 v0.3 入口。若启动器选择了其他端口，在实际地址后加 /merge-v03.html。

新玩法也能独立导出为纯静态 H5：

~~~text
python tools/export_v03.py --output .local/h5-v03
python -m http.server 8767 --bind 127.0.0.1 --directory .local/h5-v03
~~~

然后访问 [独立 H5](http://127.0.0.1:8767/)。导出包含全部本地素材，无外部 CDN 或规则后端。它是三关体验原型，尚未扩展为比赛所需的 50 关。实现、验关报告与试玩结果见 [v0.3 文档](docs/technical/v0.3.md)。

一个复现 Tile Explorer 层叠三张消除循环的 **9 关旅行原型**。Python 负责规则与关卡，浏览器负责画面与点击。无需第三方依赖或账号，启动后可以离线玩。

v0.2 新增“候选槽小剧场”：18 种牌有自己的入槽声音与性格动作，槽内共存的特定牌面会触发 6 组双牌、2 组三牌互动，三同消除时有短暂退场反馈。声音和动画可被新操作打断，不增加消牌规则。当前为功能分支验证版，正式发布基线仍为 Git 标签 `v0.1`。

18 种原创短音已随项目打包，无需在线服务。声音采用柔和的铃音、木音、拨弦和气泡音，单段约 90–150 毫秒；组合用同一套五声音阶轻轻呼应。槽下方可关闭音效，静音后仍保留视觉互动。第一关依次取苹果、猫、汽车即可体验组合；同段表演有间隔，避免连续重复。

## 开始游玩

Windows 双击 **launch.bat**。保留启动窗口，关闭它会停止服务。也可使用 Python 3.10 或以上版本运行：

```text
python main.py
```

默认打开 `http://127.0.0.1:8765`；端口被占用时自动选择空闲端口，并打开实际地址。`python main.py --port 0` 会直接选择空闲端口，`--no-browser` 关闭自动打开网页。

Windows 的 `python` 命令不可用时，可使用 `py -3.12 main.py`（需要已安装 Python 3.12）。

## 原九关怎么玩

- 点击没有被上层牌挡住的牌，放入 **7 格暂存槽**；同图案自动靠拢，三张相同立即消除。
- 被压住的牌仍显示图案，方便观察和规划；普通点击需要先移走挡牌。
- 先结算三消，再检查满槽。第七张刚好凑齐三张时仍可继续；结算后七格全满则本局失败。
- 棋盘和暂存槽同时清空即通关，没有倒计时。9 关均可自由选择。

三个功能键均不限次数：

| 功能 | 操作与效果 |
|---|---|
| 撤回 | 把暂存槽里最近放入、仍未消除的一张牌送回棋盘；已经消除的三张不会复原 |
| 魔法笔 | 点亮魔法笔后，直接点击一张被压住的牌，把它放入暂存槽；仍遵守三消与满槽规则 |
| 重新排布 | 将暂存槽中的牌一并退回，把全部剩余牌重新排布；也可在满槽失败后使用 |

## 原九关内容

| 城市与卡通背景 | 关卡 | 牌数 | 图案种类 | 层数 |
|---|---|---|---|---|
| 巴黎 · 铁塔与云朵 | 1 / 2 / 3 | 12 / 18 / 24 | 3 / 4 / 5 | 1 / 2 / 2 |
| 京都 · 鸟居与樱花 | 4 / 5 / 6 | 27 / 30 / 33 | 6 / 7 / 8 | 3 / 3 / 3 |
| 纽约 · 港湾与天际线 | 7 / 8 / 9 | 36 / 42 / 48 | 9 / 10 / 12 | 3 / 4 / 4 |

每三关共享一座城市的卡通背景，每关有一条短知识明信片及官方来源链接。图案库共 18 种，覆盖水果、汽车与交通、宠物三组。牌量、图案数和遮挡深度逐步增加；人的实际难度仍需试玩调整。

初始牌局和重新排布后的牌局均构造可通关路线，保证至少存在一个解；玩家任意选择后不保证始终有解。这个校验用于内部验关。

进行中的牌局保存在 Python 服务内存，同一浏览器会话刷新后可继续；停止服务会结束当前牌局。已完成记录写入项目 `.local/travel-progress-v2.json`。旧版成绩不混入本版进度。

## 文件与验证

~~~text
python tools/checks.py
~~~

本地与 CI 共用这一入口：运行 Python 测试、检查全部网页 JavaScript 语法、自动发现所有 JavaScript 测试、验关、导出 H5 和检查空白。开发检查需要 Node.js 24；游戏运行不需要 Node 或 npm 依赖。

2026-10-21 的统一检查通过 57 项 Python、113 项 JavaScript、全部网页脚本语法、三关完整验解、17 文件 H5 导出及空白检查。三关分别枚举 3、8、74 个状态，全部可继续通关；该保证只覆盖当前三关。主模式和静态 H5 均通过桌面、触控模拟、键盘、恢复与窄视口复测，报告错误列表为空。Android/iOS 实机与陌生玩家试玩未完成。GitHub Actions 配置 Linux/Windows 回归，远程结果以 [PR #2](https://github.com/ApoTuT/Tile-Explorer/pull/2) 实际运行记录为准。
